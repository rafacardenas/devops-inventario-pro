# Lambda y API Gateway

## Recursos implementados
- Lambda: InventarioLambda
- API Gateway: InventarioAPI

## Funcionalidad
La función Lambda genera respuestas en formato JSON utilizando Python.

## Integración
API Gateway expone la función mediante un endpoint HTTP accesible desde navegador.

## Resultado esperado
Respuesta JSON con estado de éxito y validación de funcionamiento.
