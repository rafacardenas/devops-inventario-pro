# Monitoreo con CloudWatch

En esta sección se documenta la implementación de monitoreo utilizando AWS CloudWatch.

## Actividades realizadas

- Visualización de métricas EC2
- Creación de alarma CPU
- Configuración de dashboard personalizado

## Recursos monitoreados

- CPUUtilization
- Instancias EC2

## Objetivo

Detectar problemas de rendimiento y visualizar métricas en tiempo real.
